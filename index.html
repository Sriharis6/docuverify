Module-by-Module Audit Trail

Methodology

Six-Module Forensic Pipeline

Each uploaded document passes through six independent analysis engines. Scores are computed per module and fused into a weighted integrity index.

MODULE 01
Error Level Analysis
Re-saves the image at a known JPEG quality and measures pixel-level compression differences. Edited regions show abnormally high or low error levels.
  • Compression variance uniformity
  • High-frequency noise distribution
  • Re-save artifact localization
MODULE 02
Copy-Move Detection
Extracts SIFT/ORB feature keypoints and matches them within the same image. Clusters of spatially separated matches indicate cloned or duplicated regions.
  • Keypoint descriptor matching
  • Spatial distance filtering (>30px)
  • Cluster bounding box extraction
MODULE 03
Typography Consistency
Analyses text block edge density, character height, and anti-aliasing consistency. Inserted text from a different source often has a different stroke profile.
  • Edge density per text region
  • Character height z-score analysis
  • Anti-aliasing uniformity check
MODULE 04
Text Alignment & Baseline
Detects text baseline angles and line spacing using contour analysis. Text inserted from an external source often deviates from the document's baseline angle.
  • Baseline angle per text line
  • Deviation from document median
  • Inter-line spacing variance
MODULE 05
OCR & Logical Integrity
Runs OCR on the document and validates field-level logic: expiry date must exceed issue date, DOB must precede issue date, and year values must be plausible.
  • Date chronology validation
  • Temporal sequence plausibility
  • ID field format checks
MODULE 06
EXIF & Metadata Audit
Reads EXIF tags for images or PDF metadata streams. Editing software signatures (Photoshop, GIMP, Canva) and stripped metadata are flagged as anomalies.
  • Software tag screening
  • Creation vs. modification date
  • Metadata completeness check

About This System

DocuVerify — Forensic Document Analysis

DocuVerify is a multi-signal forensic analysis system designed to identify potential modifications in document images and PDFs. Rather than rendering a binary "fake or genuine" verdict, the system produces a scored forensic audit across six independent analysis modules.

Each module targets a distinct vector of document manipulation: pixel-level compression artifacts, spatial duplication of content, typographic inconsistencies, layout misalignment, logical field errors, and file provenance metadata.
